# MT Elevator
Simple FiveM elevator script

# Preview
https://youtu.be/T50Ek6QIv8k

# Features
- Simple React UI
- Dinamic buttons:
  - If it has only 2 levels it'll show arrows instead of multiple levels buttons
- Elevator custom sound
- Create unlimited elevators with unlimited levels

# Requirements
ox_lib
ox_target
